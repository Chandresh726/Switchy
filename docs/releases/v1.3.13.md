# Switchy v1.3.13

Fixes the bundled company icons for UI Path, Glean, Nutanix, and ServiceNow.

- Replaces deleted or rate-limited image URLs with current official-site assets for UI Path, Glean, and Nutanix, and a cached domain favicon for ServiceNow. ServiceNow's direct image endpoint fails when embedded in Chrome.
- Keeps new company imports and quick-add presets from restoring the broken URLs.

Existing company records retain their saved logo URLs when the application updates. Edit a company's Logo URL to change an existing record. The audited local production database was backed up and repaired separately.

No application logic, database schema, or automatic data migration changes are introduced.
