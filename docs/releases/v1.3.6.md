# Switchy v1.3.6

- Keep the Mac awake during scraping and matching, independently of whether scheduled scraping is enabled.
- Share sleep protection across overlapping work and release it when idle. Apply setting changes to running work immediately.
- Replace timed sleep-assertion renewal with a process-bound helper, confirm registration with macOS, and restore protection if the helper exits unexpectedly.
- Move the keep-awake toggle into a compact Power section between Scraper Settings and Resume Parser.
- Preserve retry budgets across system suspension and defer scraper dispatch during maintenance-only macOS wakes.
- Migrate Postman to Workday and Swiggy to SmartRecruiters. Retire the obsolete JioHotstar Lever source when its replacement JioStar Workday board is already tracked, preserving jobs and history.
- Accept null optional Workday listing metadata and report rejected fields without logging payload values. Keep incomplete listings protected from missing-job archival.
- Include the fetch stage, offset, and HTTP status in Eightfold first-page failures.

Keep-awake prevents automatic idle sleep. The display can sleep; closing the lid, explicit sleep, and low-battery conditions can still suspend the Mac. Enabling the scheduler alone no longer keeps the Mac awake between runs.

Existing keep-awake preferences and local job, application, and scrape history are preserved. This release requires Node.js 24.

Validation includes full workspace verification, live read-only Postman and Swiggy listing/detail checks, a real macOS assertion acquisition/release check, and packaged-runtime smoke tests. The release workflow builds Linux x64, Linux arm64, macOS arm64, and Windows x64 runtimes.
