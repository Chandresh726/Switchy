# Switchy v1.3.21

Fixes scrape sessions appearing idle when the running company was on another
page of the history list.

- Shows session-wide successful, partial, failed, running, waiting, and cancelled
  counts at the bottom of the session overview card, alongside the finished total.
- Removes status counts that applied only to the current company page.
- Places running companies first and waiting companies next before pagination.
  Finished sessions return to alphabetical pagination.
- Keeps the selected page during live updates and when the session finishes.
- Uses actual scrape outcomes for finished work, so partial and failed results
  are not counted as successful merely because their queue items completed.

Scraper fetching, maintenance budgets, scheduling, and reliability safeguards
are unchanged. No database migration is required.
