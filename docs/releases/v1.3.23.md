# Switchy v1.3.23

Fixes repeated Eightfold crawl restarts after rate limiting and replaces generic
multi-location labels with actual location names.

- Saves completed Eightfold listing pages across retries and process restarts.
  Changed queries, first-page identities, totals or expired checkpoints force a
  fresh crawl. Resumed snapshots remain partial to protect archival safety.
- Paces Eightfold requests, reduces listing/detail concurrency and drains
  in-flight requests before deferring with the longest reported cooldown.
- Limits rate-limit recovery to 30 minutes from the company's first attempt,
  replacing the previous six-hour deadline. Clears old queue errors when a new
  attempt starts and labels cooldowns and retry times clearly.
- Uses structured location names across dashboard, job and company views.
  Secondary locations participate in city filtering and location search.
  Count-only listings wait for details before applying unresolved location filters.
- Repairs saved count/empty location labels using existing local location arrays.
  The repair preserves application state, matching history and scrape timestamps,
  updates the derived AI fingerprint, and requires no additional scraping.

Validation covers persisted retry recovery through temporary SQLite connections,
in-flight throttling, checkpoint invalidation, queue deadlines, location filtering,
repeat ingestion, API/UI contracts and full workspace verification.
