# Switchy v1.3.18

Switchy downloads less data and prepares automatic updates while you keep using
the app. Installation still waits for active work to finish and, for automatic
updates, for Switchy tabs to close.

- Smaller runtime archives exclude SQLite build sources and binaries for other
  platforms. Duplicate dependency files share archive storage without changing
  module resolution paths.
- New runtimes install Chromium's headless shell instead of full Chromium.
  Browser revisions continue to reuse the shared local cache.
- Interrupted runtime downloads resume across restarts, retry transient failures,
  and verify the complete checksum before installation.
- Settings report download progress and preparation stages. A requested restart
  wakes browser reconnect checks immediately and polls every one to five seconds.
- Filesystem copy-on-write speeds snapshots and restores where supported. Full
  data backups, migration coordination, readiness checks, and rollback remain in
  place. Normal work resumes before old update artifacts are pruned.

Update preferences and existing local data are preserved. The smaller runtime
benefits this download; the new updater behavior applies once this version runs
your lifecycle manager or you use the new CLI.

Validation includes workspace tests and builds, interrupted-download HTTP
fixtures, snapshot and rollback regressions, archive round trips, packaged app
smoke tests, and a fresh headless-only browser launch on macOS.
