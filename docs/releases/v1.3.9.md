# Switchy v1.3.9

- Recognize Cloudflare browser challenges separately from rate limits. Workday makes one recovery attempt using a live browser session for listing and detail requests. Persistent challenges finish with a clear error instead of retrying for hours.
- Scrape one Workday company at a time, fetch job details sequentially, and space API requests by at least 1.5 seconds. Allow longer listing sweeps at the slower pace.
- Preserve server-requested cooldowns for genuine throttling, spread retries with jitter, and reduce cooldown penalties after successful requests. Defer Workday detail throttling rather than accepting missing descriptions.
- Show retry times and "Waiting for retry" when cooldowns preserve the normal attempt budget.

Incomplete and resumed listings continue to protect existing jobs from archival. Browser challenges can still prevent access; this release reports those failures without repeated automatic attempts in the same run.
