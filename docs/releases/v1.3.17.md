# Switchy v1.3.17

Keeps scraper results current and prevents failed detail downloads from making open jobs look closed.

- Separates discovered listings from downloaded details. Jobvite preserves open identities after detail failures, filters before hydration, and retains usable listings when a later page fails.
- Updates existing titles, locations, salary, employment type and descriptions. Full descriptions refresh after 24 hours, with up to 50 existing described jobs selected from the current filtered listing per company run. Closed history cannot consume the refresh budget. Cheap listing metadata remains available between refreshes.
- Adds last-seen and detail-refresh timestamps, description quality and source locations through an additive Drizzle migration. Empty fields and teasers cannot erase a saved full description.
- Matches eligible existing jobs when their AI fingerprint changes, including description backfills. Unchanged refreshes do not create matching work.
- Requires confirmation before unusually large source disappearances can archive jobs. Age-archived jobs remain hidden when the source still lists them, avoiding repeated reopening.
- Supports Lever EU boards and explicit bounded pagination. Uses authoritative Ashby and Lever workplace fields, retains Ashby compensation and locations, and separates Greenhouse publication from modification dates.
- Salvages valid records from changed optional metadata and retries Phenom's null search bootstrap once.
- Shares Oracle and Uber schemas and pagination. Indexes deduplication, reduces description reads, limits actual browser lifetimes, releases HTTP capacity during backoff, and caps decoded responses at 64 MiB.
- Adds injectable scraper composition and a bounded weekly public contract check, also available as `pnpm scraper:check-contracts`.
- Orders settings sections as Scraper, Notifications, Resume parser, then Startup, power & updates.

Visa's official careers link now points to Workday. Its older feed still responds, while direct and browser-backed checks of the new board remained challenged. This release keeps the existing source and reports the canonical redirect in contract checks. Migration awaits complete parity and identity mapping to protect saved applications.

Validation includes full workspace verification with 1,409 passing tests, repeat-ingestion and matching regressions, bounded live source probes, and two migration runs against a disposable production snapshot preserving 11,962 jobs and application state.
