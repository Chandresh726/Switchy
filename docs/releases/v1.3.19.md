# Switchy v1.3.19

Restores the original AI provider settings interface while keeping the
connection persistence and model-cache improvements.

- Restores the original provider badges and compact refresh, edit, and delete
  controls. Removes the separate connection-check button and status timestamps.
- Restores the original CLI add form and executable-path editor presentation.
  Executable paths still autosave independently without losing newer edits.
- Uses the existing refresh icon to recheck CLI availability and models
  together. Saved status remains visible during background checks, and a failed
  refresh preserves the saved model list.
- Removes the added custom-provider discovery selector. Editing an existing
  manual-only provider preserves its discovery mode, models, and stored headers.

Saved API credentials, CLI authentication, feature selections, and the settings
section order are preserved. No database migration is required.
