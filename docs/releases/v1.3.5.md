# Switchy v1.3.5

- Reduce match-score query overhead and combine job badge counts into one lightweight request.
- Return smaller job lists and load company jobs, people, and activity only for the selected tab.
- Avoid duplicate description scans on nonempty search pages and cancel superseded job-list requests.
- Combine dashboard aggregates and lazy-load optional editors, people dialogs, and landing-page animation features.
- Keep job counts and company notes consistent across cached views after edits.
- Allow matching fallback probes while the primary model is cooling down.
- Remove unused code and consolidate shared UI flows.

History polling and scraper deduplication behavior are unchanged. Search continues to use substring matching. This release requires Node.js 24 and preserves the existing local data layout.

Validation includes the full workspace verification suite and packaged-runtime smoke tests. The release workflow builds Linux x64, Linux arm64, macOS arm64, and Windows x64 runtimes.
