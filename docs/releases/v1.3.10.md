# Switchy v1.3.10

Updates dependencies across the application, CLI, landing page, and demo video.

- Updates Next.js to 16.4.6, React to 19.3.1, AI SDK to 7.0.179, OpenCode client to 2.3.2, Playwright to 1.65.1, and better-sqlite3 to 13.2.0.
- Updates the CLI archive dependency, UI libraries, document parsers, Drizzle, Tailwind, and Remotion to their latest stable releases available during this update.
- Updates TypeScript to 7.0.2, Vitest to 5.1.1, ESLint to 10.15.0, Vite to 8.3.8, and pnpm to 12.23.0. Uses Microsoft's TypeScript 6 compatibility API alongside the TypeScript 7 compiler for tools that still need that API.
- Updates CI and release GitHub Actions and uses Node 24.22.3. Retains the supported Node 24 runtime family and matching Node 24 type definitions.
- Replaces vulnerable transitive dependency overrides, refreshes the lockfile, and removes obsolete package-age exceptions. The full dependency audit reports zero advisories after the update, compared with 17 before it.
- Updates runtime packaging for better-sqlite3 13, which no longer uses the bindings and file-uri-to-path packages.
- Makes full dependency auditing and demo-video typechecking part of workspace verification and CI.
- Updates the UI test's CSS expectation for jsdom 31 serialization and marks the Vitest configuration as ESM.

No database schema changes or user-data migrations are introduced.
