# Switchy v1.3.8

- Add optional startup on macOS, with a separate preference for opening the browser.
- Add automatic minor and patch updates when work has finished and Switchy tabs are closed. Major updates require an explicit download and restart.
- Combine startup, power and update preferences in Settings. Check, download and restart from the version controls in System Info.
- Protect version changes with verified downloads, data snapshots, migration recovery and process identity checks. Retain the previous runtime across ordinary restarts.
- Fix foreground command locking, stale-lock contention, lost update requests and tool discovery after login. Coordinate recovery with orphaned migration and application processes.
- Keep one background manager running between checks, reduce heartbeat writes, rotate logs and read bounded log tails.
- Add `restart`, `doctor`, `status --json`, and `update --check`, `--download` and `--apply` commands.
- Verify published runtime and npm artifacts in separate jobs that can be retried without republishing.

Startup and automatic updates default to off. Enable them in Settings in the installed production app. Node.js 24 is required.

When upgrading from a version without lifecycle support, perform one stopped upgrade:

```bash
pnpm dlx @chandresh726/switchy@latest stop
pnpm dlx @chandresh726/switchy@latest update
```

Validation includes full workspace verification and temporary-SQLite rollback tests covering the database, uploads and encryption secret. Release builds target Linux x64, Linux arm64, macOS arm64 and Windows x64.
